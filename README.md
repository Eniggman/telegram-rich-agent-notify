> **Универсальный скилл (Agent Skill) для любого ИИ-ассистента и автономного ИИ-агента (Codex, Claude Code, Antigravity, Cursor, Windsurf, AutoGen, Devin).**  
> Позволяет модели в один вызов отправлять красивые, структурированные мобильные отчёты в [Telegram Rich Messages](https://core.telegram.org/bots/features#rich-messages) через **Bot API 10.1+** и запрашивать решения у разработчика со смартфона (**Human-in-the-Loop**).

---

## 🎯 Что такое этот скилл и для кого он?

Когда современные ИИ-агенты пишут код, запускают тесты или выполняют долгие задачи в фоне, разработчик не хочет сидеть и непрерывно смотреть в консоль. 

Этот репозиторий — **готовый скилл (`SKILL.md`)**, подключаемый к **любому ИИ-агенту**. Агент автоматически обнаруживает его описание и самостоятельно решает, когда и как отправить уведомление:
- При завершении долгой задачи или сборки.
- При возникновении ошибки или падающих тестов (пряча 100 строк логов под нативный спойлер).
- Когда требуется выбор человека со смартфона (агент отправляет вопрос с кнопками или ждёт текстовый ответ прямо в Telegram).

## ⚡ Ключевые возможности

### 1. 🗂 Нативные сворачиваемые блоки (`<details><summary>`)
Вся техническая рутина, стектрейсы и diff прячутся под аккуратный спойлер Telegram с нативной анимацией раскрытия. На экране телефона только суть, а полный лог открывается по тапу.

### 2. 📈 Расширенный лимит: 32 768 знаков (Bot API 10.1+)
Классический `sendMessage` падает при 4 096 знаках. Метод `sendRichMessage` вмещает в **8 раз больше**, позволяя передавать реальные отчёты без разбивки на десяток сообщений.

### 3. 🛡 Двухуровневый гарантированный Fallback (100% надёжность)
* **Tier 1 (Разметка):** Если метод `sendRichMessage` недоступен, разметка на лету транслируется в `<blockquote expandable>` и уходит через стандартный `sendMessage`.
* **Tier 2 (Объём > 32K знаков):** Если лог превышает даже 32 000 символов, бот формирует краткую сводку в чат, а полный лог **автоматически прикрепляет файлом `.log`** через `sendDocument` (`multipart/form-data`).

### 4. 📲 Двусторонний диалог со смартфоном (Human-in-the-Loop)
Агент может приостановить работу и спросить человека:
* **Свободный текст:** Разработчик пишет со смартфона в чат бота (например: *«делай вариант 2»*), и бот возвращает этот текст в консоль агента.
* **Инлайн-кнопки:** Быстрый выбор готовых вариантов.
* **Hard 60-min TTL:** Фоновый процесс ожидания гарантированно самоликвидируется через 1 час, освобождая память и сокеты.

### 5. 🔌 Zero Dependencies
Никаких тяжёлых библиотек вроде `python-telegram-bot`, `aiogram` или node-модулей. Отправка работает через встроенный .NET `HttpClient` в PowerShell и стандартный Python 3 без единого `pip install`.

## 🛠 Как подключить скилл к своему ИИ-агенту

### Для Codex / Claude Code / Antigravity / Windsurf / Cursor:
Просто поместите папку скилла в каталог ваших скиллов:
* Глобально: `~/.codex/skills/telegram-notify/`, `~/.claude/skills/telegram-notify/` или `~/.gemini/config/skills/telegram-notify/`
* Внутри проекта: `.skills/telegram-notify/`

Агент автоматически подхватит манифест [`SKILL.md`](SKILL.md) и начнёт использовать его при запросах:  
*«Я отойду от компа, если тесты упадут или будет вопрос — скинь мне в телегу»*.

## 💻 Примеры вызова из терминала / скриптов

### 1. Конфигурация (`telegram.json`)
Создайте конфигурационный файл с вашим токеном:
```json
{
  "bot_token": "1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ",
  "chat_id": "123456789"
}
```

### 2. Быстрые примеры

#### Отправка красивого отчёта с логами под спойлером:
```powershell
.\scripts\send-notify.ps1 `
    -Title "Тесты CI/CD" `
    -Status Success `
    -Message "Все 42 интеграционных теста успешно пройдены." `
    -Details (Get-Content ./test.log -Raw) `
    -DetailsSummary "Развернуть вывод тестов"
```

#### Запрос подтверждения у человека со смартфона:
```powershell
$reply = .\scripts\send-notify.ps1 `
    -Title "Деплой на прод" `
    -Message "Собрать релиз v2.4.0 и выкатить на production-сервер?" `
    -Options @("1. Выкатывай", "2. Подожди, проверю", "3. Отмена") `
    -WaitReply `
    -TimeoutSeconds 900

Write-Host "Разработчик ответил: $reply"
```

## 🔒 Безопасность

* **Белый список `chat_id`:** Бот принимает сообщения строго от владельца. Запросы посторонних отбрасываются.
* **Защита от Prompt Injection:** Весь пользовательский ввод экранируется (`html.escape`), скрытые zero-width Unicode-символы удаляются.
* **Никаких сторонних серверов:** Все запросы идут напрямую между вашим компьютером и официальным `api.telegram.org` по HTTPS.
